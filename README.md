# HBR Toolbox — 绯染天空 / Heaven Burns Red 伤害计算器

Web 版全能红烧天堂计算工具箱，支持伤害计算、白值计算、OD/破坏/打分、遭遇战出分、受击伤害、排轴等。

> 本项目绝大多数代码由 AI 编写，且为作者第一个项目，如有 bug 和建议请多多提 issue。

## 在线使用

**GitHub Pages（国内可能不稳定）**: [roywu0922.github.io/hbr_calc_web](https://roywu0922.github.io/hbr_calc_web)

**Vercel Pages（需科学上网）**: [https://hbrtoolbox.vercel.app/](https://hbrtoolbox.vercel.app/)

## 功能模块

### 伤害计算

- **技能参数**：最大/最小威力、技能等级、基础差值、Hit 数、白值加成、宝珠、Token、特殊、偏向、暴击、武器/属性弱点
- **自定义加攻/减防/弱点区**：技能数据库（可编辑、添加自定义技能），按层数/被动/宝珠/等级计算面板
- **被动 & 装备**：被动加攻/减防/爆伤区 + HP 耳环、戒指、项链
- **OD 计算**：原始 hit、附加 hit、耳环系数、OD 率、目标数
- **破坏计算**：技能 DR、敌人 DR、4 种连击、破坏耳环/项链、加权破坏率 + 逐 Hit 明细
- **打分预估**：难度/回合/词条/盾分，自动计算总分
- **ex打分模式**：其它乘区 OD 倍率切换（1.1/1.2/1.3 → 1.5/2.5/3/3.5/4）；打分计算 ex 开关（ex 回合系数、删盾分、基础分 10w、伤害分按万缩放、自动填入阈值 20亿/系数 1/词条 3）
- **浮动概率可视化**：SVG 概率分布曲线 + 连击 Hit 权重，悬停查看精确概率（特征函数法）
- **属性记录/计算**（浮窗）：6 角色力/灵/智/运 → HP偏/DP偏/智偏/运偏，可拖拽、最小化

### 白值计算

- 62 名角色全数据（截止 26.6.5）
- 三层输出：基础状态值 → 合计状态值（含偏向/配装/专武）→ 有效值 & 共鸣有效值
- 支持等级/徽章/转生/突破/偏向/配装预设/专武/缺失 SS 修正

### 额外功能

- **便捷 OD 计算**：原始 hit、附加 hit、固定 OD%、耳环系数（0/10/12/15）、OD 上升量
- **加权破坏计算**：敌人 DR/最大破坏率/初始破坏率、技能 DR/Hit 数、4 种连击、耳环/项链
- **便捷打分**：直接输入总伤害估算打分（支持 ex 模式）
- **遭遇战出分**：5 阶段伤害 × 分段线性打分 + 回合分衰减 × 词条
- **受击伤害计算**：体力/精神/偏向 → 技能强度插值 → 加防乘区（印记/项链/被动） → 均伤 & 浮动范围

### 排轴表

- **排轴详表**：6 角色排轴，每回合前排 3 角色（角色选择 + 行动描述 + SP 消耗/获得 + OD 获得 + 破坏）、后排 3 角色（SP 获得）
- 回合类型：普通 / 追加 / OD内 / 前置OD1-5 / 后置OD1-5
- **ex打分**：OD 上限 300/120 → 500/200，新增 OD4/OD5 回合，OD 消耗按 ex 公式自动计算
- 显示选项下拉：破坏/追击/遭遇战/ex打分 折叠收纳
- **排轴简表**：回合轴视图，回合 × 行动轴 × 当前OD，支持标题/作者/分数/回合/备注元数据
- **轴表记录**：保存/加载/复制/删除/搜索/批量删除，支持按分数、回合排序，支持 JSON 导出/导入备份
- **分组归类**：支持新建/重命名/删除分组，按分组过滤和归类
- IndexedDB 自动保存 + 手动存档，刷新不丢失
- 风格切换：多达 25 种风格可供选择

### 技能数据库

- 支持编辑/删除内置技能、添加自定义技能
- 拖动排序，计算器下拉菜单同步更新顺序

### 计算指南

- 内置图文版伤害计算教程（Obsidian md → HTML 构建脚本生成）
- 截图自动压缩（WebP），加载飞快

### 计算历史

- IndexedDB 本地持久化，支持标签/备注编辑、加载、复制、删除、批量删除
- **搜索 & 排序**：按标签/备注搜索，按时间/标签/分数/回合排序
- **分享码**：导出当前配置为编码字符串，他人可粘贴导入
- **JSON 导出/导入**：支持导出全部历史为 JSON 文件备份
- **配置对比**：选择两条历史记录并排对比差异，差异高亮
- **分组归类**：支持新建/重命名/删除分组，按分组过滤
- **云端同步**：登录后数据跨设备同步（Supabase）

### 主题 & 体验

- 暗/亮双主题切换，毛玻璃（Glass-morphism）UI
- **外观自定义**：主题色（预设 + 取色器）、背景图片（URL/上传 + 透明度）、组件透明度
- **自定义鼠标指针**：系统 / 圆点+圆环（大小可调）/ 40+ 动画角色 / 39 个静态立绘（duelo）
- **字体自定义**：文字/数字分别设置，商务到可爱多种字体
- **交互动画**：卡片悬停发光、按钮高光扫过、页签切换过渡、伤害数字弹跳
- **更新公告**：新版本弹窗通知

## 本地开发

```bash
git clone https://github.com/RoyWu0922/hbr_calc_web.git
cd hbr_calc_web
npm install
npm run dev # http://localhost:5173
npm run build # 构建到 dist/
```
